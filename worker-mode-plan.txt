Worker Mode (Role-Based Access) — Implementation Plan
=====================================================

Context
-------
Shop owners/managers need full access to reports, settings, and financial data.
But technicians on the floor only need to input work orders and check inventory
levels — they shouldn't see financial reports or be able to change settings.

This plan adds a simple "Mode Switch" on app startup.


Roles & Permissions
-------------------

ADMIN MODE (Full Access):
- Dashboard (with financial stats)
- Work Orders
- Customers
- Companies
- Vehicles
- Workers
- Inventory (full: view, add, edit, delete, see prices)
- Suppliers
- Expenses
- Reports
- Settings

WORKER MODE (Limited Access):
- Dashboard (basic stats only, no revenue/profit)
- Work Orders (full create/edit — workers need this)
- Inventory (view stock levels only — no prices, no editing)


How It Works
------------
1. App starts → Mode selection overlay appears
2. User clicks "Admin Mode" or "Worker Mode"
3. Navigation shows only allowed pages for that mode
4. Trying to access restricted page redirects to Dashboard
5. "Switch Mode" button in sidebar to change modes
6. Closing app resets mode (asks again on next open)


Implementation Details
----------------------

1. AUTH STORE (src/store/authStore.ts) — NEW FILE
   - Simple Zustand store (NOT persisted)
   - mode: 'admin' | 'worker' | null
   - setMode(mode) — set current mode
   - isAdmin() — returns true if admin mode

2. MODE SELECT COMPONENT (src/components/ModeSelect.tsx) — NEW FILE
   - Full-screen overlay that blocks app until mode selected
   - Two big buttons: "Admin Mode" and "Worker Mode"
   - No PIN, no password — just click to select

3. APP.TSX MODIFICATIONS
   - Check if mode is null → show ModeSelect overlay
   - Wrap routes with mode protection

4. LAYOUT.TSX MODIFICATIONS
   - Filter navigation items based on mode
   - Worker sees only: Dashboard, Work Orders, Inventory
   - Add "Switch Mode" button at bottom of sidebar

5. DASHBOARD.TSX MODIFICATIONS
   - Hide revenue and financial stats when in worker mode
   - Show only: services count, open orders, low stock alerts

6. INVENTORY.TSX MODIFICATIONS
   - In worker mode:
     - Hide "Add Product" button
     - Hide cost price column
     - Hide sell price column (or show without Rp amount)
     - Hide Edit/Delete buttons
     - Hide "Adjust Stock" button
     - Show only: product name, category, stock quantity

Verification Steps
------------------
1. Start app → mode selection should appear
2. Select "Worker Mode" → only Dashboard, Work Orders, Inventory in sidebar
3. Type /reports in URL → should redirect to Dashboard
4. Create a work order → should work normally
5. Go to Inventory → no prices visible, no edit buttons
6. Click "Switch Mode" → mode selection appears
7. Select "Admin Mode" → all navigation items visible
8. Close and reopen app → mode selection appears again (not remembered)
